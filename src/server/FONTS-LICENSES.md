# Self-hosted font licenses

Mote downloads these Google Fonts webfont subsets to `assets/fonts/` the first time it starts:

- [Inter](https://fonts.google.com/specimen/Inter) — [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt)
- [Newsreader](https://fonts.google.com/specimen/Newsreader) — [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt)
- [Source Code Pro](https://fonts.google.com/specimen/Source+Code+Pro) — [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/sourcecodepro/OFL.txt)
